DSA + C++ — 60 DAY PLAN
20 blocks, 3 days per block

RULES
- Treat every topic as first-time learning, even if already completed before.
- Known topics: move faster, but still review theory + implementation + representative problems.
- New topics: learn theory, implement from scratch, then solve problems.
- Target: ~400 LeetCode questions over 60 days.
- For every problem: understand brute force -> optimize -> identify pattern -> code in C++ -> state time/space complexity.
- Keep a mistake log and revisit failed problems during revision.
- Do not count a problem as "done" if you only copied a solution.

DAILY WORK METHOD
1. Learn/revise theory.
2. Implement the core algorithm in C++ without copying.
3. Solve 2-3 guided problems.
4. Solve the remaining assigned problems independently.
5. Record pattern + key insight + complexity.
6. Re-solve failed problems after 24-72 hours.
7. Every 3rd day: spend the final part of the session revising the previous two days.
8. From Day 30 onward, include at least one problem where the topic is not disclosed.
9. From Day 45 onward, increasingly practice mixed problems.
10. The final measure is pattern recognition and independent implementation, not checklist completion.
