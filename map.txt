HOW TO READ THIS FILE
──────────────────────────────────────────────────────────────────────────────────────────

  Each asset entry contains:
    • ID          — Unique string key (matches assetRegistry.ts and inspector)
    • Type        — One of: TILESET SLICE | ANIMATED STRIP | GM SPRITE | IMAGE |
                   ISO BLOCK | ISO OVERLAY
    • Description — Human label and what the sprite represents
    • Canvas Pos  — Where the asset's card appears on the 2400px-wide atlas canvas
    • Frame Size  — Width × Height of ONE animation frame (or the tile)
    • Animation   — Number of horizontal frames and playback speed in FPS
    • Source      — Relative path from the project root to the PNG file
    • Crop Rect   — (TILESET SLICE only) pixel rectangle [x, y, w, h] inside the
                   mega-tileset PNG to extract; crop region = (x,y)→(x+w,y+h)
    • Strip Info  — (ANIMATED STRIP only) total strip width, frame layout formula
    • Faces       — (ISO BLOCK only) hex colours for the three visible faces

ASSET TYPE LEGEND
──────────────────────────────────────────────────────────────────────────────────────────

  TILESET SLICE  — A single tile cut from the 16px or 32px mega-tileset PNG.
                   Rendered by cropping [x,y,w,h] from the source sheet.
                   Main tilesets:
                     spr_tileset_sunnysideworld_16px.png  — 16×16 base tiles
                     spr_tileset_sunnysideworld_32px.png  — 32×32 hi-res tiles

  ANIMATED STRIP — A horizontal strip PNG where frames are packed left-to-right.
                   Frame N occupies x = N × frameWidth, y = 0.
                   Rendered by stepping through frames at the given FPS.

  GM SPRITE      — A standalone single-frame PNG exported from GameMaker Studio.
                   Path is inside Sunnyside_World_Gamemaker/sprites/<name>/<uuid>.png

  IMAGE          — A plain standalone PNG, no animation, no cropping needed.

  ISO BLOCK      — A procedurally drawn isometric diamond block (no PNG file).
                   Rendered at runtime with canvas 2D API using the face hex colours.

  ISO OVERLAY    — Same as ISO BLOCK but drawn as a transparent overlay layer.
