================================================================
IMPLEMENTATION NOTES
================================================================

1. IMAGE RENDERING — ALL pixel-art sprites must use:
   CSS:    image-rendering: pixelated;
   Canvas: ctx.imageSmoothingEnabled = false;

2. SCALE — Never scale to non-integer multiples. Use 2x, 3x, or 4x.
   Native sprite sizes are 7-16px — at 3x = 21-48px which fits most HUD elements.

3. 9-SLICE CONTAINERS — For scalable containers:
   CSS border-image approach:
     border-image: url('path/to/container.png') 4 fill / 4px / 0 stretch;
   Canvas draw approach:
     Draw 9 sub-images manually (TL, TC*stretch, TR, LC*stretch, C*fill, RC*stretch, BL, BC*stretch, BR)

4. PROGRESS BAR COMPOSITING:
   To draw a bar at percentage P (0.0 to 1.0):
     frameIdx = Math.floor(P * 6)  -- gives 0 through 6
   Or: draw redbar_00 as the empty background track,
       tile redbar_01 through redbar_05 for the fill region,
       place redbar_06 as the right end cap.

5. LABEL STRIPS (action prompt, name tags):
   Measure text width, then:
     draw label_left at x=0
     tile label_middle from x=4 to x=textWidth+8
     draw label_right at x=textWidth+8
